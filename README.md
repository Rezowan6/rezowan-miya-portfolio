# Rezowan Miya — Developer Portfolio

A modern, responsive and professional developer portfolio built with React, TypeScript, Vite and Tailwind CSS.

The portfolio showcases my technical skills, projects, development experience, services, certificates and contact information.

- Responsive design for mobile, tablet and desktop
- Dark / Light theme support
- Smooth scrolling navigation
- Scroll spy active navigation
- Animated section reveals
- Mobile navigation menu
- Interactive project showcase
- Certificate preview modal
- Professional contact section
- Reusable and maintainable React components
- Type-safe development with TypeScript
